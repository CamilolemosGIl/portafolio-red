# Portafolio RED

Pagina web estatica del portafolio academico sobre modelos de evaluacion de recursos educativos digitales.

## Desarrollo local

Para verla en el navegador:

```bash
python3 -m http.server 8001
```

Luego abre:

```text
http://localhost:8001
```

## Edicion

El contenido principal esta en `index.html` y los estilos estan en `styles.css`.

## Publicacion

Esta pagina se puede publicar como sitio estatico en GitHub Pages, Netlify, Vercel o Cloudflare Pages. Para que los cambios hechos desde este entorno queden publicados, conecta este directorio a un repositorio remoto y despliega desde la rama `main`.
